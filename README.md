Woodyz 🪵✨
Woodyz is an e-commerce mobile application built with Flutter that connects artisans with customers who appreciate handcrafted wood furniture and products.

📖 Overview
Artisans can showcase their products, while customers can:

Browse and explore unique handcrafted items.

Save product details pages for later viewing.

Contact artisans directly via their Instagram accounts.

Build a personalized collection of favorite products.

🚀 Features
Multi-screen navigation: Home, Explore, Saved, and Profile for Customers, and My Uploads, Upload and Profile for Artisans.

Product details page: Includes artisan info, product description, and save option.

Social integration: Customers can reach artisans through Instagram.

Authentication: Email/Password login and personal informations signup.

Backend integration: Connected to a PHP/MySQL API for product and user data.

UI/UX polish: Custom scrollbars, styled buttons, and chip-based skill/category selection.

🛠️ Tech Stack
Frontend: Flutter (Dart)

Backend: PHP + MySQL

Database: MariaDB/MySQL

Authentication: Custom PHP API

Hosting: localhost (currently)

📂 Project Structure
lib/ → Flutter app source code

lib/core/widgets → mostly reused widgets

lib/features/auth/view/ → customer pages

lib/features/auth/view/artisan/ → artisan pages

lib/features/auth/view/widgets/ → private widgets for some pages

lib/features/controller/ → connection to database classes and functions

lib/features/home/ → home pages

assets/ → Images, fonts and icons
